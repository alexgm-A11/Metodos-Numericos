Interpretación matemática Paso 1

Una empresa de telecomunicaciones necesita dimensionar la capacidad C (en Mbps) de un enlace de datos. El tiempo de espera promedio de los paquetes, según un modelo de colas M/M/1 simplificado, es:

T(C) = 1 / (C − 8.5) − 0.35·ln(C − 2)Dominio válido: C > 8.5 (estabilidad del sistema)

La capacidad óptima es aquella donde el tiempo de espera se anula. Se plantea entonces la ecuación f(C) = 0:

f(C) = 1 / (C − 8.5) − 0.35·ln(C − 2) = 0

Justificación del intervalo [a, b] Paso 2

Se evalúa f(C) por signos para localizar un cambio de signo. Cuando C → 8.5⁺, el término 1/(C−8.5) → +∞, de modo que f(C) → +∞. Cuando C crece, ese término se aproxima a 0 mientras −0.35·ln(C−2) decrece sin límite, por lo que f(C) → −∞. Existe entonces una raíz en algún punto intermedio:

C (Mbps)f(C)Signo
9.0+1.3190+
10.0−0.0611−

Como f(9) > 0 y f(10) < 0, hay cambio de signo ⇒ se garantiza una raíz en [a, b] = [9, 10], dentro del dominio válido C > 8.5.

Programa — Método de Bisección Paso 3

Ajusta el intervalo, la tolerancia o el número máximo de iteraciones y ejecuta el método.

// Método de Bisección — f(C) = 1/(C-8.5) - 0.35*ln(C-2)
function f(C) {
  return 1 / (C - 8.5) - 0.35 * Math.log(C - 2);
}

function biseccion(a, b, tol, maxIter) {
  let iter = [];
  let xrAnt = null;
  for (let i = 1; i <= maxIter; i++) {
    const xr = (a + b) / 2;
    const fxr = f(xr);
    const err = xrAnt === null ? null : Math.abs((xr - xrAnt) / xr) * 100;
    iter.push({ i, a, b, xr, fxr, err });
    if (err !== null && err < tol) break;
    if (f(a) * fxr < 0) b = xr; else a = xr;
    xrAnt = xr;
  }
  return iter;
}

Interpretación matemática Paso 1

Una empresa evalúa migrar un sistema on-premise hacia la nube. El costo acumulado de mantenerlo en servidores propios, en miles de soles, en función del tiempo t (años):

C₁(t) = 45 + 12t

El costo acumulado de operarlo en la nube (migración inicial + costo variable exponencial por consumo proyectado):

C₂(t) = 20·e^(0.4t)

El punto de equilibrio ocurre donde ambos costos se igualan, es decir, la raíz de:

f(t) = C₁(t) − C₂(t) = 45 + 12t − 20·e^(0.4t) = 0

Justificación del intervalo [a, b] Paso 2

Se evalúa f(t) entre 0 y 5 años:

t (años)f(t)Signo
0+25.000+
3+14.598+
5−42.777−

En t = 0 el costo local es menor (la nube exige inversión inicial), pero como C₂(t) crece exponencialmente termina superando a C₁(t), que crece de forma lineal. Como f(0) > 0 y f(5) < 0, hay cambio de signo ⇒ raíz garantizada en [a, b] = [0, 5].

Programa — Método de Falsa Posición Paso 3

Ajusta el intervalo, la tolerancia o el número máximo de iteraciones y ejecuta el método.

// Método de Falsa Posición — f(t) = 45 + 12t - 20*e^(0.4t)
function f(t) {
  return 45 + 12 * t - 20 * Math.exp(0.4 * t);
}

function falsaPosicion(a, b, tol, maxIter) {
  let iter = [];
  let xrAnt = null;
  for (let i = 1; i <= maxIter; i++) {
    const fa = f(a), fb = f(b);
    const xr = b - fb * (a - b) / (fa - fb); // interpolación lineal
    const fxr = f(xr);
    const err = xrAnt === null ? null : Math.abs((xr - xrAnt) / xr) * 100;
    iter.push({ i, a, b, xr, fxr, err });
    if (err !== null && err < tol) break;
    if (fa * fxr < 0) b = xr; else a = xr;
    xrAnt = xr;
  }
  return iter;
}

Problema 1 · Método de Punto Fijo Sesión 3

Un centro de datos debe mantener la temperatura de una sala de servidores en equilibrio. La temperatura de equilibrio T, en °C, satisface:

T = 18 + 8e−0.15T

Se emplea directamente la forma de iteración T = g(T) y la aproximación inicial indicada en la guía:

g(T) = 18 + 8e−0.15T    |    T0 = 20

Programa — Método de Punto Fijo Paso 3

La guía indica mostrar cada iteración, la variable, la función evaluada y el error relativo porcentual. El criterio de parada es εa ≤ 0.01% o 50 iteraciones.

// Punto Fijo — T = 18 + 8e^(-0.15T)
function g(T) {
  return 18 + 8 * Math.exp(-0.15 * T);
}

Problema 2 · Método de Newton-Raphson Sesión 3

Una empresa desea dimensionar un sistema de almacenamiento. El tiempo promedio de respuesta t, en milisegundos, se obtiene resolviendo:

f(t) = t³ − 7t − 5 = 0

La solución positiva representa el tiempo de respuesta asociado a una condición de operación. Para Newton-Raphson se usa:

tn+1 = tn − f(tn) / f′(tn)    |    f′(t) = 3t² − 7

La guía no fija un valor inicial para este problema; se propone t₀ = 2 como valor inicial positivo y cercano a la raíz positiva.

Problema 3 · Método de la Secante Sesión 3
